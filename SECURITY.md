# Segurança e privacidade

## Escopo

SIBERIA é um protótipo em desenvolvimento. Este documento não representa certificação, conformidade legal comprovada ou aprovação institucional.

## Não publique neste repositório

- Dados pessoais ou dados de saúde identificáveis.
- Imagens reais de prontuários, formulários, assinaturas ou documentos de identificação.
- Senhas, chaves de API, tokens, certificados ou arquivos de configuração com segredos.
- Relatórios internos, detalhes de infraestrutura privada ou informações confidenciais de instituições.

Use dados sintéticos para exemplos e testes públicos.

## Relato de vulnerabilidades

Não publique detalhes exploráveis de uma possível vulnerabilidade em uma issue pública. Até existir um canal privado de divulgação formalmente definido, entre em contato com os mantenedores por um meio privado apropriado e forneça apenas os detalhes necessários para a triagem inicial.

## Princípios de tratamento

Qualquer uso futuro de dados reais exige avaliação específica de finalidade, autorização, base legal, minimização, acesso, retenção, segurança e governança institucional. A publicação deste repositório, por si só, não autoriza o tratamento de dados de saúde.
